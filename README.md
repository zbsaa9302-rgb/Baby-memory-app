Baby's Memory Book app! 🌸
Here's what it can do:
Adding memories — Click "+ Add Memory" to write a note, set the date and your baby's age, and upload photos, videos, audio clips, or documents (like a hospital bracelet scan or a letter you wrote her).
Media support — Photos display as thumbnails, videos play inline, audio and PDFs are stored with a file icon.
Tags — Organize by milestone, everyday, funny, love, or growth so she can filter and browse by type when she's older.
Card colors — Each memory card gets its own pastel color, making it feel like a real scrapbook.
Search & filter — Quickly find any memory by keyword or tag.
